# 🐍 Python Programming & Internship Practice

Welcome to my Python repository! This repository contains a structured collection of Python programs, coding exercises, logical problems, and coursework completed during my learning journey and Anudip/internship modules.

## 📁 Repository Structure & Contents

Here is an overview of the concepts and projects included in this repository:

* **`condtionalprog/` & Conditional Statements**
  * `3and5.py` - Check if a number is divisible by both 3 and 5
  * `if-else.py`, `elif.py`, `match.py` - Decision-making and branching logic
  * `grade.py` - Student grading system based on marks
  * `traffic.py` - Traffic signal simulator using conditional logic
  * `drive.py` - Age/eligibility check for driving

* **Loops & Patterns (`loops/`, `pattern_star/`)**
  * `pythonforloop.py` - Iteration examples using `for` and `while` loops
  * `pattern.py` & `pattern_star.py` - Pyramid, star, and numeric pattern printing programs

* **Core Logic & Mathematical Programs**
  * `leap.py` - Leap year verification program
  * `palindrome.py` - String/Number palindrome checker
  * `factorial.py` - Factorial calculation using loops/recursion
  * `stopwatch.py` - Simple interactive timer/stopwatch application

* **Strings & Data Structures**
  * `stringmethods.py` - Built-in string manipulation functions
  * `strings(f-string).py` - Formatting strings using modern f-strings
  * `stringslicing.py` - Advanced string slicing techniques
  * `SET.py` - Working with Python sets and set operations
  * `listcomprehension.py` - Concise list creation techniques

* **Anudip & Internship Modules (`anudip/`, `internship_module1/`)**
  * Practical assignments, mini-tasks, and training exercises from professional internship sessions.

* **Data Analysis & Visualization (`Seaborn/`)**
  * Exploratory data analysis and plotting scripts using Seaborn and Python data libraries.
